# Security Policy

## Supported Versions

AMCore releases security fixes for the latest published minor version.
See [AMCore Releases](https://github.com/alex-morozov84/AMCore/releases) for
the current release and upgrade notes.

Older minors do not receive backports. Downstream products must upgrade to
the supported AMCore minor for upstream support. Product owners who choose
to cherry-pick a fix maintain that change themselves. See the
[fork update guide](docs/operations/updating-a-fork.md#beta-compatibility-and-release-notes).

## Reporting a Vulnerability

Report suspected AMCore vulnerabilities privately by emailing
[mail@alex-morozov.com](mailto:mail@alex-morozov.com). Keep vulnerability
details out of public issues, pull requests and discussions.

Include the affected version or commit, a short description, the conditions
that reproduce the issue, and the impact. Include a mitigation if you know
one. Remove credentials and private user data from the report.

We aim to acknowledge reports within a few days. We will keep you updated on
the status of the fix and coordinate disclosure if needed. We do not promise
a fix deadline. Tell us if you prefer to remain anonymous when we credit reporters.
